# videos/ —— 内置素材目录

放在这个目录里的视频会通过 `extraResources` 一起打进安装包，成为「内置素材」。

## 当前内容

目录里预置了 **1 个示例素材**（`樱花-二次元.mp4`，约 1.4MB），
目的是让用户装完就能立刻「应用壁纸」，而不是面对一个空素材库。

## 为什么没有内置全部素材

原项目的素材（`AuthorVideos/`）单个文件 5～47MB，17 个文件合计约 **460MB**。
全部塞进安装包会让分发体积从 ~90MB 膨胀到 ~550MB，所以默认不内置，
改成由应用内的「在线素材」页按需下载到用户素材目录。

## 想要内置更多素材

```bash
# 下载清单里的全部素材（约 460MB）
node scripts/fetch-materials.js

# 只下载前 3 个，快速验证打包流程
node scripts/fetch-materials.js --limit 3
```

下载完成后重新执行 `npm run dist:win`，这些视频就会进入安装包的
`resources/videos/` 目录，首次启动即可在素材库中看到。

## 自己放素材

直接把 mp4 / mov / m4v / webm 文件拷进来即可，文件名就是素材标题。
文件名里用 `-` 分隔的片段会自动变成标签，例如：

```
二次元-原神-发梢.mp4   →   标签：二次元 / 原神 / 发梢   分类：二次元
```

> 注意：内置素材无法被真正删除，用户执行「删除」时只会把它从列表中隐藏，
> 可以通过「恢复内置素材」重新显示。
